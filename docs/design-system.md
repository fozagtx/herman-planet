# Design system

The site uses Paper and Ink: calm, warm, direct.

| Token | Value | Use |
|---|---|---|
| Paper | `#efeeea` | Page background |
| Surface | `#f7f7f5` | Cards |
| Sunk | `#e6e5e0` | Hover, skeletons, inset fields |
| Ink | `#1d1730` | Text, primary buttons |
| Peach, coral, lavender | `#ffcf8a`, `#f6a19a`, `#c9b7f2` | Sound, Lyrics and Production notes |
| Stamp | `#edff00` | Live, playing, progress |

Type is Geist for text and Instrument Serif for display headings. Every card uses the `.surface` class. Buttons are pills with 44px touch targets and press feedback (`.press`). Colour appears only where it means something.

Pages are built mobile first and checked at 375px wide with no sideways scroll. All motion stops for visitors who ask for reduced motion.
