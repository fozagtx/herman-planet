# Content and sources

Nothing on the site is invented. When the team's own words were not available, content comes from published sources and the page says where.

| Content | Source |
|---|---|
| Song stories | Unorthodox Reviews, Ghana Music, Beatz Nation, The Vaultz, DCLeakers, Citi Newsroom. Each story links to its source. |
| How the pack was built | The Upper Entertainment, Ghana Music, Unorthodox Reviews, Wikipedia (Black Love), The Vaultz |
| Streams | Spotify artist page and Audiomack, counted 27 Nov 2026, kept in `src/lib/stats.ts`. Spotify's API no longer exposes play counts, so update them by hand. |
| She Get notes | Drafted from release coverage and labelled "From the release coverage" until the team rewrites and approves them. Their timestamps are estimates. |
| Influences | Unorthodox Reviews and The Vaultz |
| Sample data | Tagged "Sample" everywhere and never charged |
